1.  **Iteration**
    - **Description:** Using loops to repeat steps in a task for systematic processing.
    - **Category:** [[brute-force-algorithm|Brute-force algorithm]]

2.  **Brute Force**
    - **Description:** Trying every possible solution to find the correct one by exhaustive search.
    - **Category:** [[brute-force-algorithm|Brute-force algorithm]]

3.  **Simulation**
    - **Description:** Directly modeling a process step-by-step to understand its behavior.
    - **Category:** [[brute-force-algorithm|Brute-force algorithm]]

4.  **Frequency Counting**
    - **Description:** Counting occurrences of items in a dataset for analysis and pattern detection.
    - **Category:** [[hashing-algorithm|Hashing algorithm]]

5.  **Sorting**
    - **Description:** Arranging data in a specific order to organize and prepare it for other operations.
    - **Category:** Sorting algorithm type

6.  **Two Pointers**
    - **Description:** Using two pointers to traverse data, often sorted, to find relationships efficiently.
    - **Category:** Divide-and-conquer algorithm

7.  **Sliding Window**
    - **Description:** Maintaining a window that moves over data to solve subarray or substring problems.
    - **Category:** [[brute-force-algorithm|Brute-force algorithm]]

8.  **Greedy Algorithm**
    - **Description:** Making locally optimal choices at each step, aiming for a global optimum, but not always guaranteed.
    - **Category:** Greedy algorithm

9.  **Hashing**
    - **Description:** Using hash functions to map data to fixed-size values for efficient lookups and indexing.
    - **Category:** [[hashing-algorithm|Hashing algorithm]]

10. **Recursion**
    - **Description:** A function calling itself to solve smaller, self-similar instances of a problem.
    - **Category:** Recursive algorithm

11. **Memoization**
    - **Description:** Optimizing recursive algorithms by storing and reusing results of expensive calls.
    - **Category:** Dynamic programming algorithm

12. **Prefix Sum / Cumulative Sum**
    - **Description:** Pre-calculating prefix sums to enable quick range sum queries in arrays.
    - **Category:** Dynamic programming algorithm

13. **Binary Search**
    - **Description:** Efficiently searching sorted data by repeatedly halving the search space.
    - **Category:** Divide-and-conquer algorithm

14. **Divide and Conquer**
    - **Description:** Breaking down a problem into smaller subproblems, solving them, and combining solutions.
    - **Category:** Divide-and-conquer algorithm

15. **Backtracking**
    - **Description:** Systematically exploring solutions and reverting when a path leads to a dead end, used for search problems.
    - **Category:** Backtracking algorithm

16. **Dynamic Programming**
    - **Description:** Solving problems by breaking them into overlapping subproblems and storing their solutions for reuse.
    - **Category:** Dynamic programming algorithm

17. **Bit Manipulation**
    - **Description:** Performing operations directly on bits for efficient low-level computations and optimizations.
    - **Category:** Randomized algorithm

18. **Graph Traversal (BFS & DFS)**
    - **Description:** Systematically visiting nodes and edges in a graph to explore or search graph structures.
    - **Category:** Search algorithm

19. **Tree Traversal Algorithms (Inorder, Preorder, Postorder)**
    - **Description:** Methods to visit all nodes in a tree in specific orders for processing tree data.
    - **Category:** Recursive algorithm

20. **String Matching Algorithms (KMP, Rabin-Karp)**
    - **Description:** Algorithms for efficiently finding occurrences of patterns within text.
    - **Category:** Search algorithm

21. **Two Heaps**
    - **Description:** Using two heaps to maintain order statistics like median in dynamic datasets efficiently.
    - **Category:** Greedy algorithm

22. **Disjoint Set Union (DSU) / Union-Find**
    - **Description:** Managing disjoint sets and their unions, useful for connectivity problems.
    - **Category:** [[brute-force-algorithm|Brute-force algorithm]]

23. **Topological Sort**
    - **Description:** Ordering vertices in a DAG based on dependencies, used in scheduling and dependency resolution.
    - **Category:** Sorting algorithm type

24. **Linear Search**
    - **Description:** Sequentially checking each element in a list until the target is found or the end is reached.
    - **Category:** Search algorithm

25. **Caesar Cipher**
    - **Description:** A simple substitution cipher where each letter is shifted a fixed number of positions down the alphabet.
    - **Category:** Encryption algorithm

26. **QuickSort (Randomized Pivot)**
    - **Description:** A divide-and-conquer sorting algorithm that uses a randomly chosen pivot to improve average-case performance.
    - **Category:** Randomized algorithm
