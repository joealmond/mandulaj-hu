Hashing algorithms work similarly to the searching algorithm. But they contain an index with a key ID. In hashing, a key is assigned to specific data.

Examples: Hash Table/Dictionary Implementation, Rabin-Karp String Matching, Bloom Filter, Consistent Hashing, Cryptographic Hash Functions, Polynomial Rolling Hash

**How to Identify:**

- **Problem Description Clues:** Look for requirements to "quickly check if an element exists," "count frequencies," "group items," "map keys to values," or "efficiently find duplicates." Problems involving character counting, anagrams, or symbol frequency often suggest hashing.
- **Input/Output Pattern:** Often involves processing collections of items (arrays, strings) and needing to efficiently look up or count occurrences. Output might involve counts, groups, or checks for existence.
- **Core Idea:** Use hash functions and hash tables (dictionaries, maps) to achieve fast average-case lookup, insertion, and deletion operations.
- **Keywords:** "frequency," "count," "lookup," "check if exists," "duplicates," "anagrams," "map," "dictionary," "hash table," "unique elements."
