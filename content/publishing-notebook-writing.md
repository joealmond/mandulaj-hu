This site begins in Obsidian, but the vault is not the website. The vault is the private workspace where a note can be incomplete, contradictory, or connected to material that should never leave my devices.

A note becomes eligible for the site only when I deliberately set its `publish` property to `true`. Folder location does not publish anything by itself. That single switch keeps the default simple: every new note stays private.

The next step is not an automatic upload. The public copy is rebuilt through a boundary that keeps only the content and metadata the site is designed to expose.
